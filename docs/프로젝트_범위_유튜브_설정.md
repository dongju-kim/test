# 키움 1초 스캘핑 — 프로젝트 범위 · 유튜브 · 설정 목록

> **본문은 `docs/전체정리_차트_영상_설정.md` 이다.**  
> 이 파일은 이전 초안 + 유튜브 설명란용이다. 질문이 「차트봉 · 영상 · 봉의 차이 · ±%」로 수정됐다.

대화에서 정한 엔진과 나중에 UI로 열 숫자까지 한곳에 모았다.  
**구현은 나중.** 이 문서는 범위와 기본값, 사용자가 바꿀 칸을 고정하기 위한 것이다.

용어는 쉽게 쓴다. 「잠근다」고 하지 않는다. 매수 뒤에는 **1차를 기다린다.** 체결이 안 늘면 **아래 지정가를 걸어 둔다.**

---

## 0. 한 줄

**오늘 3분 완성봉으로 방을 고르고, 그 방 안에서 1초 돈의 방향(D)과 힘의 커짐(H)으로만 사고 판다.**  
어제 3분봉·가격 MACD·RSI·볼린저·VWAP·체결강도(FID 228)는 타점에 쓰지 않는다.

## 1. 프로젝트 범위

### 1.1 만드는 것

| 층 | 하는 일 | 지금 | 나중 |
|---|---|---|---|
| 아침 종목 | 어제 일봉 2~3일 + 주봉 자리 + 제외종목 + ±% 창으로 오늘 볼 목록만 줄임 | 규칙만 | 키움 조건검색·자체 필터 UI |
| 국면 엔진 | 3분 **완성봉만.** 한 봉에 방 하나. 우선순위 고정 | 코드 있음 | 숫자 UI |
| 타점 엔진 | 1초 D·H. 얇지 않음 / 체결이 늘어남 / 추격·걸어두기 | 코드 있음 | 숫자 UI |
| 주문 | 추격 지정가, 걸어두기, 손절·급락·1·2차 | 가격 규칙 있음 | 키움 주문 연결 |
| 여러 종목 | 같은 초 추격만 줄 세움. 신규 1개 | 코드 있음 | 자리 수 UI |
| 금액 | 위험·계좌·호가 한도 중 가장 작은 값 | 규칙만 | 슬라이더 UI |
| 화면 | 3분과 1초를 같은 축에 겹치지 않음. 매수 −30초~+60초 | 그림만 | 차트 UI |
| 기록 | 왜 샀는지, 왜 안 샀는지, 왜 팔았는지 | 없음 | 일지·유튜브용 다시보기 |

### 1.2 일부러 안 만드는 것

- 가격 MACD + RSI + 볼린저 + VWAP로 **타점** 내기 (예전 README 전략. 이 프로젝트의 타점이 아님)
- 체결강도(FID 228, 당일 누적)로 사기
- 건수를 D·H에 **곱하기** (1주 연타가 진한 초록이 됨)
- 추매, 손절 미루기
- 어제 3분봉으로 오늘 방 만들기 (갭)
- 조건이 부족한 초를 **시장가로 메우기**
- D<0.5만 보고 팔기 (H 1차와 겹치고 빈 초에 흔들림)
- 승률 예측 「신뢰점수」
- 해외, 숏, 선물, 복사매매

### 1.3 두 엔진을 섞지 않음

1. **방** — 3분 완성봉. 진행 중 봉·꼬리·2분 혼용 금지.
2. **타점** — 1초 D와 H. 방이 열어 준 곳에서만.

같은 날 **방 숫자와 H 숫자를 같이 바꾸지 말 것.** UI에도 경고를 띄운다.

### 1.4 방과 문 (고정 골격)

우선순위: `급락 → 돌파 시도 → 눌림 → 급등 → 횡보 → 관망`

| 방 | 신규 | 1·2차 | 전량 |
|---|---|---|---|
| 급락 / 개장 급락 | 닫음 | 없음 | 즉시 |
| 돌파 시도 | 연다 | 없음 | 손절만 |
| 눌림 | 연다 (10:00 이후) | 없음 | 손절만 |
| 급등 / 개장 급등 | 닫음 (추매 없음) | 연다 | 손절·2차 |
| 횡보 · 관망 · 개장 관망 | 닫음 | 없음 | 없음 |
| 09:00 전 · 완성봉 0개 | 닫음 | 없음 | 없음 |

진짜/가짜는 소분류가 아니다. **방 × H.**

- 가짜 급락 ⊂ **눌림** (종가가 MA20을 깊게 안 깸)
- 진짜 급락 = **급락 방** (H로 취소하지 않음)
- 눌림 ≠ 하락 돌파의 반대. 급등/돌파 **이후** MA20 근처 조정.

### 1.5 매수 두 갈래 · 매도 갈래

**추격 (여섯 칸 모두 참)**  
방 열림 → 18분 대기 아님 + H 준비됨 → 얇지 않음 → 체결·대금이 늘고 있음 → D>0.5를 3초 → H>0이 2~3초 커짐  
가격: 돌파=매도1호가(미체결 포기), 눌림=직전가

**걸어두기**  
방은 열림 + 얇지 않음 + D>0.5 + H≥0, **체결은 안 늘어난 상태**  
가격: 이전 3분봉 몸통의 아래서 2/3. 현재가보다 낮고 손절보다 위일 때만. 시장가 아님.

**매도**  
A 손절·급락 = 즉시 (기다리지 않음)  
B 1차 = 급등 + 양수 H 첫 축소. **산 뒤 H가 한 번 더 커지거나 12초가 지난 뒤**  
C 2차 = 급등 + H≤0. 기다리지 않음  
D 실패 돌파 = 돌파 후 N봉 안에 급등 실패 → 잔량 (기본 꺼둠)  
E 최대 보유 = 분 천장 (기본 꺼둠)  
F D로 팔기 = **안 씀**

### 1.6 제품으로 나중에 붙을 것

- 키움 실시간 체결 → 1초 매수/매도 대금 (빈 초는 D를 0.5로 채우지 않음)
- 3분봉 시각이 시작이면 +3분
- 10:25 재시작: 오늘 3분봉만 재생. 1초는 저장본이 있을 때만 바로
- 설정 화면 (이 문서의 칸)
- 페이퍼 / 실전 스위치
- 일지와 「매수 −30초~+60초」 다시보기 (유튜브·복기용)

## 2. 구글에서 가져온 것 — 아침 종목에만 씀

키움 0150/0156, 단타 검색식, 갭 3%, 주봉 이평, 관리종목 제외는 **장중 타점이 아니다.**  
아침에 **오늘 볼 종목을 줄이는 체**로만 쓴다. 장중 방은 오늘 3분봉만 본다.

흔한 항목과 이 프로젝트에서의 자리:

| 구글에서 흔한 것 | 여기서 |
|---|---|
| 전일 종가 대비 시가 갭 3~10% (갭 단타) | **기본은 반대.** 시가가 전일 종가 ±3% **안**인 종목. 큰 갭은 오늘 3분 방이 어제와 안 맞음. UI에서 「갭만」으로 뒤집을 수 있음 |
| 첫 1·3분봉 시가 대비 ±3% 꼬리/종가 | 개장 워밍업 숫자와 맞춤. **아침 체가 아니라 장중 방** (개장 ±1%가 기본, ±3%는 UI) |
| 주봉이 이평 위, 주봉 정배열 | 아침 체 **켬.** 큰 자리만 본다. 장중 방에는 안 넣음 |
| 일봉 2~3일 양봉·거래대금 | 아침 체 **켬.** 대화에서 정한 것 |
| 전일 동시간 거래량 200% | 아침 체 **꺼둠.** 켜면 테마 추격이 됨 |
| 52주·60일 신고가 | 아침 체 **꺼둠.** 돌파 전략용 |
| 시가총액·주가 범위·거래대금 | 아침 체 **켬.** 대형·두꺼운 호가 |
| 관리·경고·우선주·ETF·정지 제외 | 아침 체 **켬.** 안전 |
| 호가 잔량비·외인·기관 | 타점 **안 씀.** 아침 체도 기본 꺼둠 |
| 1분봉 +1%, 1분 대금 3억 | 타점 **안 씀.** 방은 3분, 타점은 1초 D·H |
| 가격 익절 +2~4%, 시간 익절 30분 | 익절 %는 **안 씀** (H 1·2차). 최대 보유 분만 UI에 꺼둔 채 둠 |

전일봉과 주봉의 차이:

- **전일·최근 2~3일 일봉** = 어제 힘(양봉인지, 대금이 붙었는지). 오늘 갭이 크면 이 힘과 오늘 시가가 끊긴다.
- **주봉** = 몇 주 자리(이평 위인지, 몸통 위인지). 일봉이 좋아도 주봉이 길게 깨져 있으면 아침 목록에서 뺀다(기본).
- 둘 다 **방을 만들지 않는다.** 목록만 줄인다.

## 3. 유튜브

### 3.1 제목 초안

1. 키움 스캘핑, 3분으로 방 고르고 1초로만 산다 (D·H)
2. 왜 가격 MACD는 안 쓰나 · 체결이 안 늘면 시장가 금지
3. 매수 뒤 바로 팔리지 않게 · 1차는 12초 또는 H가 한 번 더 커진 뒤

설명란에는 1번을 메인으로, 2·3은 시리즈 카드.

### 3.2 설명란 (복사해서 올림)

```
키움 자동매매 스캘핑을 「방」과 「타점」으로 나눕니다.

방은 오늘 3분 완성봉만 봅니다. 어제 3분봉은 갭 때문에 오늘 방에 쓰지 않습니다.
타점은 1초 돈의 비율(D)과 그 힘의 커짐(H)만 봅니다.
가격 MACD, RSI, 볼린저, VWAP, 당일 누적 체결강도는 타점이 아닙니다.

매수는 두 가지입니다.
• 추격: 방이 열리고, 호가가 얇지 않고, 체결·대금이 늘고, D가 0.5 위, H가 커질 때.
  돌파는 매도1호가, 눌림은 직전가. 미체결이면 포기합니다.
• 걸어두기: 방은 열렸는데 체결이 안 늘면, 이전 3분봉 몸통의 아래서 2/3에 지정가만 겁니다.
  조건이 부족하다고 시장가로 메우지 않습니다.

매수는 드뭅니다. 그게 맞습니다.

매도
• 손절가, 급락 방 = 즉시. 기다리지 않습니다.
• 1차 = 급등 방에서 양수 H가 처음 작아질 때.
  다만 사자마자 같은 봉우리에서 팔지 않게,
  산 뒤 H가 한 번 더 커지거나 12초가 지난 뒤에만 냅니다.
• 2차 = 급등에서 H가 0 이하. 기다리지 않습니다.
• D만 보고 팔지 않습니다.

시간은
08:30~09:00 동시호가 봉은 버립니다.
09:00~09:18 박스만 모읍니다. 신규 없음. D·H는 계산만 합니다.
09:18~10:00 박스 종가 돌파만.
10:00 이후 돌파 + 오늘 MA20 눌림.

여러 종목이 같은 초에 추격이 열리면
원 H·원 대금·주가가 아니라
그 종목 평소 대비 체결·대금 속도로 하나만 고릅니다.
걸어두기는 줄에 넣지 않습니다.

아침 종목만 어제 일봉 2~3일과 주봉 자리, 전일 대비 시가 ±3% 같은 체로 줄입니다.
장중 방에는 어제 일봉·주봉을 다시 넣지 않습니다.

숫자는 초안입니다. 같은 날 방 숫자와 H 숫자를 같이 바꾸지 마세요.
나중에 설정 화면에서 기본값을 바꿀 수 있게 목록을 열어 두었습니다.

#키움 #자동매매 #스캘핑 #3분봉 #수급 #단타
```

## 4. 설정 철학 — UI를 네 칸으로

| UI 표시 | 뜻 |
|---|---|
| **고정** | 화면에 설명만. 끄면 이 전략이 아님 |
| **기본** | 슬라이더/칸. 우리가 정한 초안 |
| **고급** | 접어 둠. 열면 바꿈 |
| **꺼둠** | 스위치 꺼짐. 켜면 다른 맛이 됨 |
| **안 씀** | 왜 없는지 한 줄. 켜는 칸 없음 |

경고 두 줄 (설정 저장 시):

1. 방 그룹과 수급 그룹을 **같은 날 같이** 저장하지 말 것.
2. 아침 종목 ±%를 바꿔도 **장중 방 숫자는 그대로**다.

#### 전일 대비 오늘 시가 갭 (기본 켬)

| 칸 | 기본 | 범위 | 뜻 |
|---|---|---|---|
| 갭 필터 | 켬 | 켬/끔 | |

#### 주봉 (기본 켬) — 「전일봉과 다른 층」

| 칸 | 기본 | 범위 | 뜻 |
|---|---|---|---|
| 주봉 체 | 켬 | 켬/끔 | 장중 방에 미사용 |

| 주봉 이격 하한 | −3% | −8~0 | 이평을 조금 깨도 허용 |

| 전일 종가 vs 주봉 고점 | 꺼둠 | −3% 안 | 주봉 고점 근처만 |

전일봉과 주봉을 **한 숫자로 합치지 않음.** UI도 칸을 나눈다.  
예: 어제 +2%여도 주봉이 MA20을 −5%로 깨면 기본 목록에서 탈락.
