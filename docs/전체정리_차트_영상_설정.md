# 전체 정리 — 차트봉 · 영상 · 설정 칸

이전 질문에 「유튜브 / 구글 / 주봉」이 섞여 있었다.  
이 문서는 **수정된 질문** 기준이다.

1. 지금까지 정한 내용을 한곳에 모은다.  
2. **차트봉**이 무엇을 보고, 봉과 봉의 차이가 어디 쓰이는지 적는다.  
3. 이미 만든 **영상·그림**이 각각 무엇을 보여 주는지 적는다.  
4. 국면·매수·매도마다 나중에 UI로 열 **숫자·스위치**를 적는다.  
5. **구현은 나중.**

용어: 매수 뒤에는 **1차를 기다린다.** 체결이 안 늘면 **아래 지정가를 걸어 둔다.** 「잠근다」고 하지 않는다.

## 0. 한 줄

**오늘 3분 완성봉으로 방을 고르고, 그 방 안에서 1초 돈의 방향(D)과 힘의 커짐(H)으로만 사고 판다.**

어제 3분봉, 진행 중 봉, 꼬리, 가격 MACD/RSI/볼린저/VWAP, 당일 누적 체결강도는 타점이 아니다.

## 1. 지금까지 합의된 골격

### 1.1 두 엔진 (질문을 섞지 않음)

| | 방 | 타점 |
|---|---|---|
| 봉 | 3분 **완성봉만** | 1초 (봉이 아님. 막대 H) |
| 한 칸 | 한 봉에 방 하나 | 한 초에 D 하나, H 하나 |
| 우선순위 | 급락→돌파 시도→눌림→급등→횡보→관망 | 방이 연 곳에서만 |
| 안 씀 | 진행 중 봉, 꼬리, 어제 3분 | 가격 지표, 건수를 H에 곱하기 |

같은 날 **방 숫자와 H 숫자를 같이 바꾸지 말 것.**

### 1.2 방과 문

| 방 | 신규 매수 | 1·2차 | 전량 |
|---|---|---|---|
| 급락 / 개장 급락 | 닫음 | 없음 | 즉시. H 무시 |
| 돌파 시도 | 연다 | 없음 (다음 봉이 급등 전) | 손절만 |
| 눌림 (10:00 이후) | 연다 | 없음 | 손절만 |
| 급등 / 개장 급등 | 닫음 (추매 없음) | 연다 | 손절·2차 |
| 횡보 · 관망 | 닫음 | 없음 | 없음 |
| 09:00 전 · 완성봉 0개 | 닫음 | 없음 | 없음 |

가짜 급락 ⊂ 눌림 (종가가 MA20을 깊게 안 깸).  
진짜 급락 = 급락 방. H로 취소하지 않음.  
눌림 ≠ 하락 돌파의 반대. 급등/돌파 **이후** MA20 근처.

### 1.3 매수 두 갈래

**추격** — 여섯 칸 모두 참.  
방 열림 ∧ 18분 지남 ∧ H 준비됨 ∧ 얇지 않음 ∧ 체결·대금이 늘음 ∧ D>0.5를 3초 ∧ H>0이 2~3초 커짐.  
돌파=매도1호가(미체결 포기). 눌림=직전가.

**걸어두기** — 방은 열림 + 얇지 않음 + D>0.5 + H≥0, **체결은 안 늘어난 상태.**  
이전 3분봉 **몸통의 아래서 2/3.** 현재가보다 낮고 손절보다 위. 시장가로 메우지 않음.

신호가 드문 게 정상이다.

### 1.4 매도

| 갈래 | 언제 | 기다림 |
|---|---|---|
| A 손절 · 급락 | 가격 선 / 급락 방 | 없음. 1초여도 |
| B 1차 | 급등 + 양수 H가 처음 작아짐 | 산 뒤 H가 한 번 더 커지거나 12초 |
| C 2차 | 급등 + H≤0 | 없음 |
| D 실패 돌파 | 돌파 후 N봉 안에 급등 실패 | **꺼둠** |
| E 최대 보유 | N분 | **꺼둠** |
| F D로 팔기 | — | **안 씀** |

### 1.5 시간

- 08:30–09:00 동시호가 봉 버림. 첫 완성봉 종가=09:03 (키움 시각이 시작이면 +3분)
- 09:00–09:18 박스만. 신규 없음. D·H는 계산만
- 09:18–10:00 박스 **종가** 돌파만
- 10:00– 돌파 + 오늘 MA20 눌림
- 10:25 재시작: 오늘 3분봉만 재생해 방은 즉시. 1초는 저장본이 없으면 ≈40초

### 1.6 여러 종목 · 금액

같은 초 추격만 비교. 점수 = 0.40 건수속도 + 0.35 대금속도 + 0.15 D깊이 + 0.10 H연속.  
원 H·원 대금·주가 금지. 한 초 신규 1, 동시 보유 1~2. 걸어두기는 줄에 안 넣음.

한 종목 금액 = min(위험, 계좌, 호가).  
위험 0.4% / 손절 1.0% · 자리1 30% · 자리2 20% · 3초 대금 10% · 매도1 잔량 30%.

### 1.7 아침 종목만 쓰는 큰 봉

어제 **일봉 2~3일**, (원하면) **주봉 자리**, 시가 갭 **±3%** 는 **오늘 볼 목록**만 줄인다.  
장중 방·타점에 다시 넣지 않는다.

## 2. 차트봉 — 무엇이 다르고, 어디를 보나

화면에는 봉이 여러 겹이다. **같은 축에 칸 수를 맞추면 거짓이 된다.**

### 2.1 네 겹

| 겹 | 한 칸 | 쓰는 곳 | 안 쓰는 곳 |
|---|---|---|---|
| 주봉 | 한 주 | 아침 목록 (큰 자리) | 장중 방 |
| 일봉 | 하루 | 아침 목록 (어제 2~3일) | 장중 방 |
| **3분봉** | 3분 | **방** | 타점 |
| **1초** | 1초 | **타점 D·H** | 방 |

3분 한 봉 안에 H는 **180칸**이다.  
예시 그림에서 봉 12개 아래 H를 12칸으로 줄여 그린 것은 **이야기용**이다. 실제 화면은 축이 둘이다.

그림: `axis_01_cannot_share.png`, `axis_02_two_windows.png`, `axis_03_meet_at_now.png`  
영상: `hd_zoom_in_out_demo.mp4`, `three_min_bar_hd_click_zoom_demo.mp4`

### 2.2 한 3분봉에서 보는 것 / 안 보는 것

한 봉 = 시가 · 고가 · 저가 · 종가 · 거래량.

| 보는 것 | 안 보는 것 |
|---|---|
| **종가**로 방 (박스 위/아래, MA20, 급등·급락) | **꼬리만** 박스/MA20을 뚫는 것 |
| 직전 N봉의 고저로 박스 | 진행 중 봉의 지금 가격으로 방 바꾸기 |
| 몸통(시가~종가)의 아래서 2/3 → 걸어두기 가격 | 몸통 아래를 이미 뚫고 내려간 뒤 더 따라가기 |
| 거래량으로 「조용한 횡보」 | 거래량만으로 매수 |

그림: `full_05_ma20_close.png`, `onebar_01_open.png`, `onebar_02_dont_average.png`, `onebar_03_which_bar.png`

**한 봉을 두 방으로 쪼개지 않는다.** 종가가 닫히면 방 하나.

### 2.3 봉과 봉의 차이 — UI에 올라갈 비교

나중에 사용자가 숫자로 만지는 것은 거의 다 **「이 봉 vs 저 선」의 % 또는 개수**다.

| 비교 | 기본 | 무엇과 무엇 | 쓰임 | UI |
|---|---|---|---|---|
| 지금 종가 vs 박스 상단 | 종가 > 상단 | 직전 봉들의 고점 | 돌파 시도 | 박스 폭 1.5%가 박스 크기 |
| 지금 종가 vs 박스 하단 | 종가 < 하단 | 직전 저점 | 박스 깨짐 · 급락 후보 | 같은 폭 |
| 지금 종가 vs 오늘 MA20 | ±0.3% | 오늘 3분 종가 20개 | 눌림 | 기본 |
| 지금 종가 vs MA20 아래 | 0.5% 또는 2봉 | 같은 MA20 | 급락 | 기본 |
| 지금 종가 vs 시가 | +1% / −1% | 당일 시가 | 개장 급등/급락 | 기본. ±3%로 키울 수 있음 |
| 지금 종가 vs 직전 충동 | +1% 기억 | 당일 이미 +1% | 급등 기억(추매 금지) | 고급 |
| MA5 vs MA20 간격 | 0.5% | 두 이평 | 횡보 | 기본 |
| 박스 폭 (고-저)/중간 | 1.5% | 직전 20봉 | 횡보 잠금 | 기본 |
| 이번 봉 거래량 vs 최근 | < 평균×1.5 | 3봉 vs 20봉 | 조용한가 | 고급 |
| 눌림 봉 거래량 vs 급등 봉 | < 50% | 최근 상승 최고 | 진짜 조정인가 | 고급 |
| 직전 3분 몸통 아래서 2/3 | 2/3 | 시가~종가 | 걸어두기 | 기본 (1/2로 변경 가능) |
| 지금 초 vs 직전 초 H | 작아짐 | 1초 H | 1차 | 대기 12초 |
| 최근 3초 vs 그 앞 3초 | 건수·대금 증가 | 1초 창 | 추격 확인 | 기본 |
| 최근 3초 vs 그 종목 평소 | ×2.5 · ×1.5 | 90초 EMA | 추격 확인 | 기본 |
| 오늘 시가 vs 전일 종가 | 안쪽 ±3% | 일봉 | 아침 목록만 | 기본 |
| 주봉 종가 vs 주봉 MA20 | 위, 이격 −3%~+15% | 주봉 | 아침 목록만 | 기본 |
| 어제 종가 vs 3일 고점 | −3% 안 | 일봉 | 아침, **꺼둠** | 꺼둠 |

**봉의 차이**를 한 슬라이더로 합치지 않는다.  
「±3%」는 자리가 다르다. 시가 갭 ±3%와 눌림 ±0.3%와 개장 ±1%(또는 3%)는 **다른 칸**이다.

### 2.4 꼬리 · 몸통 · 종가 (헷갈리기 쉬운 세 선)

```
고가 ───  꼬리. 방으로 안 씀. 돌파/급락 아님
        │
종가 ═══  몸통 위. 방의 결정선
        │  몸통. 걸어두기는 아래서 2/3
시가 ═══  몸통 아래
        │
저가 ───  꼬리. 눌림이 깨진 게 아님
```

가짜 돌파 = 꼬리만 박스 위, **종가는 박스 안.**  
가짜 급락 = 꼬리만 MA20 아래, **종가는 ±0.3% 안.**

### 2.5 화면에 그리는 법

- 위: 3분 가격 봉. 방 이름, 박스, MA20.
- 아래: 같은 **지금**에 맞춘 1초 H (색 네 가지)와 D.
- 클릭한 3분봉 = 그 180초만 확대. 줌아웃은 참고. **줌아웃에서 새 매수 신호 없음.**
- 복기: 매수 −30초 ~ +60초. 세로선 = 매수 / 1차 / 2차 / 손절.

그림: `zoom_01_three_views.png`, `zoom_02_verdict.png`, `full_06_hd_legend.png`

H 색: 진한 녹=커짐, 연한 녹=작아짐(1차), 진한 빨=깊어짐, 연한 빨=얕아짐.

## 4. 매수·매도 시점을 차트에 그리는 법

### 4.1 추격 매수 (세로 초록 점선)

3분: 방이 돌파 또는 눌림으로 막 닫힌 뒤.  
1초: D가 0.5 위를 3초, H가 양수로 커지는 마지막 초에 가깝다.  
가격선: 돌파=매도1호가, 눌림=직전가.

### 4.2 걸어두기 (가로 노란 점선)

3분: 직전 완성봉 몸통의 아래서 2/3 높이에 가로선.  
현재가보다 낮을 때만. 이미 그 아래면 선 없음.  
1초: 체결이 안 늘어 H 추격은 닫힌 상태.

접는 때: 급락, 추격이 열림, 방이 닫힘, H가 음수로 깊어짐.

그림: `wait_buy_01_two_doors.png`, `wait_buy_02_cancel.png`

### 4.3 1차 (세로 주황)

급등 방 + 양수 H가 처음 작아진 한 초.  
매수 직후 같은 봉우리면 **안 그림.** H가 한 번 더 커진 뒤이거나 12초 뒤만.

그림: `hold_01_instant_flip.png`, `hold_wait_01_first_fade.png`, `full_14_sell_fade.png`  
영상: `video_10_sell1_fade.mp4`

### 4.4 2차 (세로 주황, 잔량)

급등 + H가 0 아래로 내려간 첫 초. 12초를 기다리지 않음.

영상: `video_11_sell2_zero.mp4`

### 4.5 손절 · 급락 (세로 빨강)

가격이 손절가. 또는 3분 방이 급락. H가 초록이어도.

영상: `video_14_real_dump.mp4`, `video_15_stop.mp4`  
그림: `case_08_09_scale_and_stop.png`

## 7. 나중에 UI로 열 칸

표시: **고정** 설명만 · **기본** 슬라이더 · **고급** 접음 · **꺼둠** 스위치 꺼짐 · **안 씀** 켜는 칸 없음.

경고: 방 묶음과 수급 묶음을 같은 날 같이 저장하지 말 것.  
아침 ±%를 바꿔도 장중 방 숫자는 그대로.  
손절·급락에 1차 대기를 묶지 말 것.

전체 칸은 `docs/ui_settings.json`. 아래는 **봉·%·시점** 위주.
