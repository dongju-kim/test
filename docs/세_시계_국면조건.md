# 세 시계와 국면 조건

말은 쉽게 쓴다. **열린다 / 닫힌다 / 잠근다** 는 쓰지 않는다.

- **국면** = 지금 장이 어떤 상태인지. 급락 · 돌파 · 눌림 · 급등 · 횡보 · 관망.
- **사도 된다 / 사면 안 된다** = 그 국면에서 새로 주문을 낼 수 있는지.
- **산다 / 안 산다** = 지금 이 초에 실제로 주문을 내는지.
- **새로 사지 않는다** = 보유는 할 수 있어도 추가 매수는 안 함.
- **나눠 판다** = 1차 · 2차.
- **3분봉이 끝났다** = 그 3분의 종가가 나왔다. (국면을 다시 보는 때)
- **바닥 점 / 천장 점** = 저점 · 고점.

코드 기준: `phase_engine.py` 의 `PhaseConfig`. 숫자는 초안이다.

상승·하락·횡보의 **큰 방향**(국면과 다른 층): `docs/상승하락횡보_큰방향.md`

## 1. 세 시계 — 무엇이 맞나

예전에 말한 **「3분봉이 끝난 뒤, 다음 3분 안의 1분봉으로 자리를 본다」** 가 맞다.  
**국면이나 저·고를 1초마다 다시 보지 않는다.**

1초는 **이미 사도 되는 상태에서, 지금 주문할지 / 1·2차로 나눌지** 만 본다.

| 시계 | 한 칸 | 언제 다시 보나 | 하는 일 | 안 하는 일 |
|---|---|---|---|---|
| **1. 국면** | 오늘 3분 **완성봉** | 3분봉이 **끝날 때만** | 장이 급락/돌파/눌림/급등/횡보/관망인지 | 진행 중 봉, 꼬리, 어제 3분, 1초 |
| **2. 바닥·천장 점** | 다음 3분 속 **완성 1분봉** | 1분봉이 **끝날 때만** | 3분이 잡은 후보를 확정하거나 점을 옮김 | 1초, 진행 중 1분, 5분으로 스윙 |
| **3. 타점** | 1초 돈의 비율 D, 힘 H | **1초마다** | 추격 / 걸어두기 / 1차 / 2차 | 국면을 바꾸지 않음. 점을 확정하지 않음 |

### 시계 1 — 국면 (3분)

09:00~09:03 봉이 09:03에 끝나면 국면 하나.  
그다음 09:03~09:06 동안은 **같은 국면을 유지**한다.  
09:06에 다음 봉이 끝나면 그때 다시 본다.

3분 한 봉에 국면은 **하나**. 우선순위: `급락 → 돌파 → 눌림 → 급등 → 횡보 → 관망`

### 시계 2 — 바닥·천장 점 (다음 3분의 1분)

3분봉이 끝나며 「여기가 바닥 후보」가 나와도, 그 자리에서 바로 사지 않는다.

그 **다음 3분**(필요하면 그다음 2~3개의 3분) 안에서 **이미 끝난 1분봉**으로만

- 점이 맞으면 **확정**
- 덜 움직이며 더 극값이면 **점을 종가로 옮김** (수명 2~3봉만)
- 세게 깨면 **점을 버림**

횡보면 바닥 점을 **찾지 않는다.**  
직전 고점 대비 대략 **1.0~3.0 × 3분 ATR** 빠진 파동에서만 찾는다.  
더 깊거나 급락이면 점은 따라가도 **새로 사지 않는다.**

1초 H의 부호만으로 점을 확정하지 않는다. 진행 중 1분봉은 안 본다.

### 시계 3 — 타점 (1초)

국면이 **사도 된다**이고, 눌림이면 **바닥 점도 확정된 뒤**에만 본다.

- 추격: 얇지 않음 + 체결·대금이 늘음 + D>0.5를 3초 + H>0이 2~3초 커짐
- 걸어두기: 얇지 않음 + D>0.5 + H≥0, 체결은 안 늘음 → 이전 3분 몸통 아래 2/3
- 1차: 급등 + 양수 H가 처음 작아짐 (산 뒤 12초 또는 H가 한 번 더 커진 뒤)
- 2차: 급등 + H≤0

빈 초의 D를 0.5로 채우지 않는다.

### 한 줄로 틀린 말 / 맞는 말

- 틀림: 「3분봉이 끝나면 1초마다 국면을 다시 본다」
- 틀림: 「1초마다 바닥·천장 점을 정한다」
- 맞음: 「3분봉이 끝날 때만 국면을 다시 본다」
- 맞음: 「다음 3분 안의 완성 1분봉으로 점을 본다」
- 맞음: 「사도 되는 국면(눌림이면 점 확정 후)에서만 1초로 산다·판다」

## 2. 국면을 보기 전에 준비하는 숫자

모두 **오늘, 이미 끝난 3분봉**만 쓴다. 지금 그려지고 있는 봉은 넣지 않는다.

| 재료 | 뜻 | 기본 |
|---|---|---|
| 시가 | 오늘 첫 3분봉의 시가 | 09:00 시가 |
| MA5 | 오늘 3분 종가 EMA 5 | 봉 5개부터 |
| MA20 | 오늘 3분 종가 EMA 20 | 봉 20개(약 60분)부터 **준비됨** |
| 박스 | 잠긴 박스가 있으면 그 고·저. 없으면 직전 최대 20봉 고·저. **지금 막 끝난 봉은 빼다** | 폭 = (고−저)÷중간 |
| 거래량 조용 | 최근 3봉 평균 < 최근 최대 20봉 평균 × **1.5** | |
| 충동 기억 | 오늘 종가가 시가보다 **+1%** 이상 이었거나, 이미 돌파/급등을 한 적 있음 | 눌림·급등에 필요 |
| 박스 고정 | 횡보로 판정되면 그때 박스를 고정. 종가가 박스 위·아래로 나가면 고정 해제 | |

08:30–09:00 동시호가 봉은 버린다. 첫 완성봉 종가는 **09:03**.

## 3. 국면별 조건 (위에서 아래로 하나만)

한 봉이 여러 조건에 겹치면 **위가 이긴다.**  
아래 숫자는 `PhaseConfig` 와 같다.

### 3.1 급락 — 사면 안 된다. 들고 있으면 바로 전량

**MA20이 준비된 뒤** (둘 중 하나면 급락)

1. 종가 < MA20 × **0.995** (MA20보다 **0.5% 이상** 아래)
2. 또는 최근 **2개** 종가가 모두 MA20 아래

**MA20이 아직일 때** (개장 급락)

1. 종가 ≤ 시가 × **0.99** (시가보다 **1% 이상** 아래)
2. 또는 봉이 **6개 이상**(18분)이고 종가 < 임시박스 하단

꼬리만 MA20 아래로 내려가고 종가는 근처면 **급락이 아니다.** 눌림 쪽으로 본다.

이 국면: 새로 사지 않는다. 걸어 둔 주문은 취소. 보유는 즉시 전량. H가 초록이어도 그대로.

### 3.2 돌파 — 사도 된다 (09:18 이후). 나눠 팔지는 않음

1. 비교할 박스가 있어야 한다. (직전 봉이 있어야 함)
2. **박스가 고정된 상태**면: 종가 > 박스 상단
3. **박스가 아직이면**: 봉이 **6개 이상**이고 종가 > 직전 구간 고점
4. 꼬리만 위에 있고 종가는 박스 안이면 **돌파 아님.** 횡보 유지.

이 국면: 추격은 **매도1호가** (미체결이면 포기). 걸어두기는 이전 3분 몸통 아래 2/3.  
1차·2차는 없다. 손절만. 다음 봉이 급등이 되면 그때부터 나눠 판다.

09:00–09:18 에는 박스만 모은다. 돌파여도 **새로 사지 않는다.**

### 3.3 눌림 — 사도 된다 (10:00 이후 + 바닥 점 확정 후)

**MA20이 준비되기 전에는 눌림으로 사지 않는다.**

모두 맞아야 한다.

1. **충동 기억**이 있다. (오늘 이미 +1% 또는 돌파/급등을 한 적)
2. 종가가 MA20 **±0.3%** 안이거나, MA20 아래여도 **0.3% 이내**인 약한 한 봉
3. 봉이 충분하면(최근 6개 이상, 거래량 있음): 이번 봉 거래량 ≤ 최근 상승 봉 최고 거래량 × **0.5**
4. 시계: **10:00 이후**에만 새로 산다. (국면 이름만 먼저 나와도 10시 전에는 안 산다)
5. 자리: **다음 3분의 완성 1분봉**으로 바닥 점이 확정된 뒤

가짜 급락 = 이 칸. 종가가 MA20을 깊게 안 깬 조정.

이 국면: 추격 가격은 **직전가**. 1차·2차는 없다. 손절만.

횡보 중에는 바닥 점을 찾지 않는다. 고점에서 **1.0~3.0 × 3분 ATR** 빠진 파동에서만 찾는다.

### 3.4 급등 — 새로 사지 않는다. 들고 있으면 나눠 팔 수 있다

**MA20이 준비된 뒤** (모두)

1. 종가 > MA20
2. 종가가 MA20과 **0.3%보다 멀리** (가까우면 눌림 자리)
3. 지금 MA20 > **3봉 전** MA20 (우상향)
4. 충동 기억이 있다
5. 박스 위를 **처음** 종가로 넘긴 봉이 아님 (그건 돌파)

**MA20이 아직일 때** (개장 급등)

1. 종가 ≥ 시가 + **1%**
2. MA5가 있으면 종가 ≥ MA5

이 국면: 추매 없음. 1차 = 양수 H 첫 축소(12초 또는 한 번 더 커진 뒤). 2차 = H≤0. 손절은 그대로.

### 3.5 횡보 — 사면 안 된다. 바닥 점도 찾지 않는다

1. 박스 폭 < **1.5%**
2. 거래량 조용 (위 표)
3. **MA20이 있으면** |MA5 − MA20| / MA20 < **0.5%**
4. **MA20이 없으면** 봉이 **8개 이상**(24분). MA5가 있으면 3봉 전 MA5 대비 **0.4%** 넘게 기울면 횡보 아님

횡보로 판정되면 그때 박스를 **고정**한다. 종가가 박스 밖이면 고정이 풀린다.

이 국면: 새로 사지 않는다. H가 커져도 안 산다. 1차·2차 없음.

### 3.6 관망 — 사면 안 된다

위 다섯이 하나도 아니면 관망.  
MA20 전이면 **개장 관망**. 급락·돌파·급등·횡보가 아직 아닌 상태.

09:00 전, 완성봉 0개(09:03 전)도 사면 안 된다.

## 4. 국면이 정해진 뒤 하는 일

| 국면 | 새로 사나 | 바닥 점 | 주문 | 매도 |
|---|---|---|---|---|
| 급락 / 개장 급락 | 아니오 | 점은 따라가도 사지 않음 | 걸어 둔 주문 취소 | 전량 즉시 |
| 돌파 | 예 (09:18+) | 돌파 자리. 저점 루틴 아님 | 1초 추격 또는 걸어두기 | 손절만 |
| 눌림 | 예 (10:00+ 그리고 점 확정) | **다음 3분의 1분으로 확정** | 1초 추격(직전가) 또는 걸어두기 | 손절만 |
| 급등 / 개장 급등 | 아니오 | 천장 후보는 1분으로 | 안 삼 | 1차 · 2차 · 손절 |
| 횡보 · 관망 | 아니오 | 찾지 않음 | 안 삼 | 없음 (이미 들고 있으면 손절만) |

추격이 되면 걸어 둔 주문은 **취소**한다. 시장가로 메우지 않는다.

시간 덧칠 (국면 이름과 별개):

- 09:00–09:18 박스만. 새로 사지 않는다. D·H는 계산만.
- 09:18–10:00 박스 **종가** 돌파만.
- 10:00 이후 돌파 + 눌림.
- 마감 15분 전 새로 사지 않는다.
