# 키움 조건검색 A~H — 이 화면에서 넣는 법

지금 연 창이 조건검색식 작성기다.  
위쪽 **대상변경**, 가운데 `숫자 < 종가 < 숫자`, 오른쪽 **추가** 가 보이면 맞다.

이 식은 **오늘 볼 종목 목록**만 줄인다.  
장중 국면(3분)이나 타점(1초 D·H)이 아니다. 한 줄씩 **추가**하면 모두 **그리고**(동시에) 맞아야 남는다.

왼쪽 위부터: `매수` 동그라미가 켜져 있으면 그대로 둔다.

---

## 0. 화면 읽는 법

| 눈에 보이는 것 | 하는 일 |
|---|---|
| **대상변경** | 제외종목 (G) |
| **일전기준** | A~F 같은 하루 조건 |
| **봉전기준** | H만. 1분·3분 이평 |
| 가운데 숫자 두 칸 | 하한 · 상한 |
| 가운데 드롭다운 (지금 `종가`) | 무엇을 비교할지 |
| **추가** | 그 한 줄을 식에 넣음 |

단위:

- 주가 = **원** 그대로 (2000, 100000)
- 거래대금 = **백만원** (3000 = 30억, 5000 = 50억, 300000 = 3,000억)
- 등락률 · 거래량비율 = **% 숫자** (1, 20, 3, 200)

---

## 클릭 순서

### 1) G — 대상변경 (제일 먼저, 한 번)

1. 왼쪽 위 **대상변경**을 누른다.
2. 제외에 체크한다: 관리종목, 거래정지, 정리매매, 투자경고·위험, ETF, ETN, 우선주, 스팩.
3. 확인.

화면 윗줄이 `<제외없음>` 에서 제외가 켜진 문구로 바뀌면 된 것이다.

### 2) A — 지금 가운데 줄을 고친다

지금 칸이 `10000 < 종가 < 20000` 이다.

1. 왼쪽 칸을 **2000**
2. 가운데가 `종가`면 **현재가**로 바꾼다 (장중 목록이면 현재가가 맞다. 종가도 장 마감 뒤에는 같다)
3. 오른쪽 칸을 **100000**
4. **추가**

저가주·너무 비싼 대형만 뺀다.

### 3) B — 전일 거래대금 50억~3,000억

1. 왼쪽 트리 **범위지정 → 거래대금** (없으면 시세분석 → 거래대금)
2. **전일** 거래대금인지 확인 (당일이면 B가 아니다)
3. `5000  <=  전일거래대금  <=  300000`
4. **추가**

키움 단위가 백만원이면 5000=50억, 300000=3,000억이다.  
억 단위 칸이면 50 ~ 3000 으로 넣는다. 한 칸만 보고 단위를 확인한다.

### 4) D — 오늘 대금 30억 이상

1. 같은 **거래대금**에서 **당일**
2. `3000  <=  당일거래대금`  (상한은 비움)
3. **추가**

장 초반에는 아직 30억이 안 찬 종목이 많다. 09:20 이후가 더 맞다.

### 5) C — 전일 종가 대비 오늘 +1%~+20%

1. **시세분석 → 가격조건 → 주가등락률**
2. 기준이 **전일 종가 대비 당일 현재가** 인지 본다
3. `1  <=  등락률  <=  20`
4. **추가**

오르는 종목만 남긴다. 장 전에는 비거나 시가 기준이 될 수 있다.

### 6) E — 오늘 저가 대비 고가 3% 이상

1. 같은 가격조건에서 **고가대비/저가대비** 또는 일중 변동(고가−저가)/저가
2. `3  <=  당일 저가대비 고가 등락률`  (상한 없음)
3. **추가**

「전일 대비 등락률」(C)과 **다른 줄**이다. C를 고치지 말고 한 줄 더 넣는다.

### 7) F — 전일 동시간 거래량 200% 이상

1. **범위지정 → 거래량비율** 또는 **시세분석 → 거래량 → 전일동시간대비**
2. `200  <=  전일동시간대비 거래량`
3. **추가**

**장중에만** 의미가 있다. 08:50에 돌리면 거의 비거나 이상해진다.

### 8) H — 선택. 지금 이평 위

1. 위쪽을 **봉전기준**으로 바꾼다
2. 분봉을 **1분** 또는 **3분** (국면과 맞추려면 3분)
3. **기술적분석 → 이동평균 → 주가이평비교**
4. `현재가 > 20이평`
5. **추가**
6. 끝나면 **일전기준**으로 다시 돌려 둔다 (다음에 A~F를 고칠 때 안 헷갈리게)

안 넣어도 식은 돌아간다.

---

## 저장 후

1. 식 이름 예: `아침목록_AH`
2. 저장
3. 조건검색 창에서 그 식을 **실시간**으로 돌린다
4. 나온 종목만 오늘 3분 국면·1초 타점의 **관심 목록**

---

## 이 식과 이 프로젝트 기본이 다른 점

A·B·D·G 는 규모·제외라서 같다.  
아래 세 개는 **다른 전략**이다. 넣으면 「이미 오른 테마」가 많이 남는다.

| 칸 | 지금 넣으려는 값 | 이 프로젝트 아침 체 기본 |
|---|---|---|
| C | 전일 대비 **+1~+20%** | 시가 갭 **안쪽 ±3%** (큰 갭 제외) |
| F | 전일 동시간 거래량 **200%** | **꺼둠** (테마 추격) |
| H | 1분/3분 현재가 > 20이평 | 아침 체에 안 넣음. 장중 3분 국면이 따로 함 |

C·F·H를 빼면, 예전에 정한 「오늘 볼 목록」에 더 가깝다.  
넣고 싶으면 넣되, **타점이라고 생각하지 말 것.**
