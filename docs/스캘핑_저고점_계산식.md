# 스캘핑 저점·고점 — 구현 식

말은 쉽게. **열린다 / 닫힌다 / 잠근다** 는 쓰지 않는다.  
기존 G / `s_n` / 밥그릇 / MA20 국면은 **배치**. 이 문서의 식에 안 넣는다.

그림 세 장:

- 점의 부등식: `docs/swing_formula_fractal.png`
- 꼬리 vs 종가: `docs/swing_formula_events.png`
- 묶기·VWAP·방아쇠: `docs/swing_formula_trigger.png`

스펙 코드: `swing_hl.py` (국면 엔진에 연결하지 않음)

입력은 **이미 끝난 봉**만. 그려지는 중인 1·3·5분봉은 배열에 넣지 않는다.

---

## 0. 봉 하나

| 기호 | 뜻 |
|---|---|
| `O, H, L, C, V` | 시가 · 고가 · 저가 · 종가 · 거래량 |
| `end` | 그 봉이 **끝난** 시각 |
| 인덱스 `i` | 오늘 그 시계에서 0부터. 진행 중 봉 없음 |

키움이 봉 **시작** 시각을 주면 `end = 시작 + 봉길이`.  
1분 첫 봉 시작 09:00 → `end` 09:01.

---

## 1. 점의 부등식 (Williams, n)

양옆 `n` 봉. 기본: 5분·3분은 `n=2`(5봉), 1분은 `n=1`(3봉).

**고점 i** (네 개, 또는 `n=1` 이면 두 개, **모두 참**):

```
H[i] > H[i-k]    k = 1, 2, …, n
H[i] > H[i+k]    k = 1, 2, …, n
```

**저점 i**:

```
L[i] < L[i-k]    k = 1 … n
L[i] < L[i+k]    k = 1 … n
```

같은 봉이 고점이면서 저점일 수 있다.  
`H[i] == 이웃` 이면 고점이 **아니다.** 등호는 탈락 (`equal_ok=False`).

숫자 예 (n=2):

| i | 0 | 1 | **2** | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|---|
| H | 100 | 102 | **108** | 103 | 101 | 104 | 105 |
| L | 98 | 99 | 101 | 100 | **97** | 99 | 100 |

- 고점 i=2: 108>100, 108>102, 108>103, 108>101 → 참. **confirm_index = 2+2 = 4**
- 저점 i=4: 97<101, 97<100, 97<99, 97<100 → 참. **confirm_index = 6**
- 봉이 0..4 까지만 있으면 저점 i=4 는 아직 점이 아니다 (오른쪽 2봉 없음).

### 알게 된 시각

| | |
|---|---|
| 점의 좌표 | 봉 `i` 의 `H[i]` 또는 `L[i]` |
| 점을 아는 때 | 봉 `i+n` 의 종가가 나온 뒤 |
| 5분 n=2 | 점 시각 + **10분** |
| 3분 n=2 | + **6분** |
| 1분 n=1 | + **1분** |

봉 `i` 가 끝나는 순간에 「여기가 바닥이다」를 알 수 있는 식은 없다.

### 3봉 = n=1

```
고점 i  ⇔  H[i] > H[i-1]  그리고  H[i] > H[i+1]
저점 i  ⇔  L[i] < L[i-1]  그리고  L[i] < L[i+1]
confirm_index = i+1
```

### 중간점 (ITH / ITL)

단기 고점만 시간 순으로 늘어놓고, 가운데가 양쪽보다 높으면 `rank=2`.  
확정은 **오른쪽 단기점의 confirm_index**. 한 단계 더 하면 `rank=3`.

## 2. 번갈아, 큰 방향

점이 고·고로 연속이면 **더 높은 고점만** 남긴다. 저·저면 더 낮은 저점만.  
남긴 뒤:

```
HH  ⇔  지금 고점 > 직전 고점
HL  ⇔  지금 저점 > 직전 저점
LH  ⇔  지금 고점 < 직전 고점
LL  ⇔  지금 저점 < 직전 저점
```

고점 둘, 저점 둘 이상일 때만:

| 조건 | 큰 방향 |
|---|---|
| HH 그리고 HL | **상승** |
| LH 그리고 LL | **하락** |
| 그 외 | **횡보**. 방아쇠 안 봄 |

예: 고 100 → 저 90 → 고 110(HH) → 저 95(HL) → 상승.

---

## 3. 한 봉의 사건 — 꼬리 vs 종가

직전 확정 저점 `SL`, 직전 확정 고점 `SH`.

```
스윕_저   ⇔  (L < SL)  and  (C >= SL)
스윕_고   ⇔  (H > SH)  and  (C <= SH)
CHoCH_하락 ⇔  C < SL
BOS_상승   ⇔  C > SH
CHoCH_상승 ⇔  C > SH     (하락 구조에서 읽을 때 이름만 다름)
BOS_하락   ⇔  C < SL
```

같은 봉에서 `스윕_저` 와 `CHoCH_하락` 은 **동시에 참이 될 수 없다.**  
종가가 `SL` 위면 스윕, 아래면 성격 바뀜.

숫자 예. `SL=10000`:

| 봉 | L | C | 사건 |
|---|---|---|---|
| 꼬리만 | 9980 | 10030 | 스윕_저 |
| 종가 깨짐 | 9900 | 9920 | CHoCH_하락. 사면 안 된다 |

`SH=11000`, C=11050 → BOS_상승. 꼬리만 11100 이고 C=10950 → 스윕_고.

1분에서 난 CHoCH 를 5분 큰 방향 전환으로 읽지 않는다.

## 4. 1분을 3분·5분으로 묶기

`step=3` 이면 3분, `step=5` 이면 5분.

```
시작 = end - 1분
그룹 = floor( (시작 - 오늘 09:00) / step분 )
```

한 그룹에 `step` 개가 **다 찬 뒤에만** 상위 봉 하나:

```
O = 첫 1분.O
H = max(그룹 H)
L = min(그룹 L)
C = 마지막 1분.C
V = sum(그룹 V)
end = 마지막 1분.end
```

09:00, 09:01, 09:02 세 개가 모여 3분봉 `end=09:03`.  
09:03, 09:04 만 있으면 그 3분은 **아직 봉이 아니다.**

5분 첫 봉: 09:00~09:04 → `end=09:05`.

## 5. 자석

**전일고저** (어제 3분 국면이 아님. 어제 **하루** 고저):

```
PDH = max(어제 정규장 H)
PDL = min(어제 정규장 L)
```

**VWAP** 은 오늘 09:00부터만. 어제 분봉을 안 섞는다.

```
TP = (H + L + C) / 3
VWAP = Σ (TP × V) / Σ V
σ²   = Σ (V × TP²) / Σ V  −  VWAP²
σ    = sqrt(max(σ², 0))
```

숫자 예: TP=9 V=100, TP=11 V=100 → VWAP=10, σ=1.

**근처** (둘 중 하나면 참):

```
|x − 선| / 선     ≤  0.002     (0.2%)
|x − 선|          ≤  0.25 × ATR_5분
```

ATR 은 Wilder 14. 봉이 14개 미만이면 ATR 항은 끈다. 퍼센트 항만.

자석 목록: PDH, PDL, 오늘 시가, VWAP, VWAP±σ, 직전 5분 저점, 직전 5분 고점.

## 6. 매수 방아쇠 — 여섯 AND

**지금 끝난 1분봉**에서만 참/거짓을 본다. 1초는 여기 없다.

`SL` = 직전 확정 3분 저점.  
`j` = 직전 확정 1분 3봉 저점.  
`H[j]` = 그 저점 봉의 고가.

| # | 식 | 거짓이면 |
|---|---|---|
| 1 | 5분 큰 방향 = 상승 (HH ∧ HL) | 사면 안 된다 |
| 2 | `SL` 이 자석 근처 | 우선순위 없음 |
| 3 | 오늘 어떤 1분봉이 `스윕_저` | 아직 자리 아님 |
| 4 | `j.confirm_index == 지금 1분 인덱스` | 점이 방금 확정된 봉이 아님 |
| 5 | 지금 `C > H[j]` | 작은 구조가 안 이어짐 |
| 6 | 지금 `C ≥ SL` | 아직 3분 저점 아래 |

여섯이 참이면:

```
사도 된다
손절 = 스윕 봉의 L  (오늘 스윕 저가 중 최저)
```

숫자 예:

- SL = 10000 (VWAP 근처)
- 스윕 봉: L=9980, C=10030 → 식 3 참
- 1분 저점봉 j: L=10010, H=10050, 오른쪽 봉이 지금 봉
- 지금 봉: C=10080 > 10050, 그리고 10080 ≥ 10000

손절 9980. 1초 D/H 는 **이 여섯이 참인 뒤**에만.

하나라도 거짓이면 사면 안 된다.

매도 방아쇠는 대칭: 5분 하락, 3분 고점 스윕_고, 1분 3봉 고점 확정, 지금 C < L[그 고점봉].

## 7. 구현 순서 (한 1분이 끝날 때마다)

1. 끝난 1분을 배열 끝에 붙인다. 진행 중 봉은 안 붙인다.
2. 3분·5분으로 묶는다. 덜 찬 그룹은 없다.
3. 각 시계에서 `n` 프랙탈 → 번갈아 → 5분은 큰 방향.
4. VWAP·σ 를 오늘 1분으로 갱신.
5. 방금 끝난 1분으로 스윕/CHoCH 를 기록.
6. 식 1~6. 참이면 손절을 적어 두고, 그때부터만 1초 타점.

다시 그려지는 점(지그재그 마지막 다리)은 쓰지 않는다.  
오른쪽 `n` 봉이 끝나기 전에 점을 배열에 넣지 않으면, 확정된 점은 이후 봉이 나와도 **안 사라진다.**
