# 눌림 데이터 수집기 (KiwoomCollector)

키움 OpenAPI+ 로 **1단계 종목 목록 만들기**와 **2단계 1분봉 받기**를 하는
MFC 대화상자 프로그램입니다. Visual Studio 2017 / 2019 / 2022 에서 열립니다.

> Visual Studio 2016 은 없는 버전입니다. 2015 다음이 2017 입니다.
> 프로젝트는 설치된 VS 의 기본 툴셋을 따라가도록 해 놨습니다.

---

## 0. 어디까지 확인했나

MFC 는 마이크로소프트 전용이라 리눅스에서 진짜 빌드는 못 합니다.
대신 **제가 쓴 MFC 기능만큼만 흉내 내는 가짜 헤더**(`tests/mfc_stub.h`)를
만들어 g++ 로 검사했습니다. 결과는 이렇습니다.

| 항목 | 결과 |
|---|---|
| 6개 소스 파일 문법 검사 (`-Wall -Wextra`) | 통과, 경고 없음 |
| 순수 계산 함수 단위 테스트 47개 | 전부 통과 |

테스트로 확인한 것은 호가 단위표와 경계값, 호가 비용, 종목 거르기
규칙(우선주·ETF·스팩·리츠), 20일 이동평균 거래대금의 최댓값,
키움 숫자 문자열 읽기, CSV 쪼개기와 감싸기, 날짜 빼기(해 넘김·윤년)
입니다.

리눅스에서 다시 돌려 보려면:

```sh
sh tests/check.sh
```

**다만 이걸로 확인 안 되는 것이 있습니다.**

* MFC 고유 동작 (메시지 맵, DDX, 대화상자 생명주기)
* OCX 이벤트가 실제로 들어오는지
* 키움이 돌려주는 항목 이름이 제가 쓴 것과 같은지
* Visual Studio 링크 단계

그래서 **처음 빌드할 때 손볼 곳이 나올 수 있습니다.** 어디를 봐야
하는지는 아래 5번에 정리해 두었습니다. 오류 메시지를 그대로 주시면
고쳐 드립니다.

그리고 **32비트(Win32)로만 빌드해야 합니다.** 키움 OpenAPI+ 는 32비트
OCX 라서 64비트 프로그램에서는 안 올라옵니다. 프로젝트에 Win32 구성만
넣어 두었습니다.

## 1. 준비물

| 준비물 | 확인 방법 |
|---|---|
| 영웅문 + OpenAPI 모듈 | 키움 홈페이지에서 OpenAPI 설치 |
| OpenAPI 사용 신청 | 키움 홈페이지에서 신청, 승인까지 시간이 걸립니다 |
| 모의투자 또는 실계좌 | 로그인만 되면 조회는 됩니다 |
| Visual Studio + **MFC** | 설치 관리자에서 "C++를 사용한 데스크톱 개발" 안의 MFC 항목을 꼭 체크 |

## 2. 딱 하나 직접 하셔야 하는 일

OCX 래퍼 클래스는 Visual Studio 가 만들어 줍니다. 제가 미리 넣어 둘 수가
없습니다. 처음 한 번만 하시면 됩니다.

1. `KiwoomCollector.sln` 을 엽니다
2. 메뉴 **[프로젝트] > [클래스 추가]** 를 누릅니다
3. **[ActiveX 컨트롤에서 MFC 클래스]** 를 고릅니다
4. 목록에서 **KHOpenAPI Control** 을 찾아 오른쪽으로 옮깁니다
5. 클래스 이름이 `CKHOpenAPICtrl` 인지 확인하고 마침을 누릅니다

`CKHOpenAPICtrl.h` 와 `.cpp` 가 만들어집니다.
이름이 다르게 만들어졌다면 아래 두 곳의 `#include` 만 고치면 됩니다.

* `KiwoomApi.cpp` 맨 위
* `MainDlg.h` 맨 위

이 단계를 건너뛰면 **빌드가 안 됩니다.** 헤더가 없기 때문입니다.

## 3. 쓰는 순서

빌드하고 실행하면 창이 하나 뜹니다. 버튼을 왼쪽부터 순서대로 누르시면 됩니다.

### ① 로그인
키움 로그인 창이 뜹니다. 아이디와 비밀번호를 넣습니다.
**비밀번호는 이 프로그램이 저장하지도, 보지도 않습니다.**
키움 로그인 창이 알아서 처리합니다.

### ② 한도 재보기
가장 먼저 이걸 돌려 보세요. 종목 하나로 1분봉이 **과거 어디까지 오는지**
재봅니다. 몇 분이면 끝납니다. 로그에 이렇게 나옵니다.

```
===== 한도 측정 결과 =====
받은 봉 62,400 개, 연속조회 70 장
기간 20260210090100 ~ 20260919152900
하루 390봉으로 치면 약 160 거래일입니다.
```

이 숫자가 **한 종목당 받을 수 있는 최대치**입니다.
이 값에 따라 2단계에 걸리는 시간이 정해집니다.

### ③ 1단계 목록
전 종목의 일봉을 2년치 받아서 분봉 받을 종목을 고릅니다.

* 우선주 / ETF / ETN / 스팩 / 리츠 / 관리종목을 먼저 뺍니다
* 남은 종목의 20일 평균 거래대금 **최댓값**을 봅니다
* 호가 비용(한 호가 ÷ 가격)이 0.15% 를 넘으면 뺍니다

결과는 `data\symbols.csv` 이고 거래대금이 큰 순서로 정렬돼 있습니다.

### ④ 2단계 분봉
`symbols.csv` 위에서부터 1분봉을 최대치까지 받습니다.
종목마다 `data\bars\005930.csv` 같은 파일이 하나씩 생깁니다.

**중간에 멈춰도 됩니다.** 다시 누르면 `data\manifest.csv` 를 보고
안 받은 종목부터 이어서 합니다. 며칠 밤에 나눠 받으셔도 됩니다.

## 4. 시간이 얼마나 걸리나

여기가 제일 중요합니다. 키움 조회 제한 때문에 **종목을 다 받으면 이틀이
걸립니다.**

널리 쓰이는 제한값은 1초 5회 / 1분 100회 / **1시간 1000회** 입니다.
시간당 1000회가 가장 빡빡해서 요청 간격을 3.6초로 잡아 두었습니다.

| 종목 수 | 요청 수 (종목당 70장) | 걸리는 시간 |
|---|---|---|
| 150 | 10,500 | 약 10시간 |
| 300 | 21,000 | 약 21시간 |
| 700 | 49,000 | 약 49시간 |

그래서 `Config.h` 의 `MAX_SYMBOLS_FOR_BARS` 를 **150** 으로 해 두었습니다.
하룻밤에 끝납니다. 익숙해지면 늘리세요.

프로그램이 시작할 때 예상 시간을 로그에 찍어 줍니다.

> **기간이 종목 수보다 중요합니다.** 부담되면 종목을 줄이시고,
> 기간은 받을 수 있는 최대치를 그대로 두세요.

## 5. 처음 빌드할 때 볼 곳

제가 확인하지 못한 값들입니다. 로그를 보시면서 이상하면 고치세요.
전부 한 파일 안에 모아 뒀습니다.

### `Jobs.cpp` 맨 위

```cpp
static LPCTSTR REC_DAILY  = _T("주식일봉차트조회");
static LPCTSTR REC_MINUTE = _T("주식분봉차트조회");
static LPCTSTR F_STAMP    = _T("체결시간");
...
static const double TURNOVER_UNIT = 1000000.0;
```

* **레코드 이름과 항목 이름**은 키움 개발가이드에 나옵니다. 다르면 여기만 고칩니다
* 받은 봉이 0개로만 나오면 십중팔구 이 이름들이 틀린 겁니다
* **거래대금 단위**는 백만원으로 잡아 뒀습니다. 로그의 억 단위 숫자가
  1000배쯤 이상하면 `1.0` 이나 `1000000.0` 으로 바꿔 보세요

### `MainDlg.cpp` 의 이벤트 번호

```cpp
ON_EVENT(CMainDlg, IDC_KHOPENAPI, 1, ...OnReceiveTrDataKh...)
ON_EVENT(CMainDlg, IDC_KHOPENAPI, 3, ...OnReceiveMsgKh...)
ON_EVENT(CMainDlg, IDC_KHOPENAPI, 5, ...OnEventConnectKh...)
```

로그인을 눌렀는데 아무 반응이 없으면 이 번호가 틀린 겁니다.
그럴 때는 Visual Studio 에서 OCX 를 고르고 속성 창의 번개 모양에서
핸들러를 추가하면 올바른 줄이 자동으로 만들어집니다.

### `Util.cpp` 의 호가 단위표

```cpp
if (price < 2000.0) return 1;
if (price < 5000.0) return 5;
...
```

거래소 규정이 바뀌면 이 표도 바뀝니다. 한 번 확인해 보세요.

## 7. 설정값

전부 `Config.h` 한 곳에 있습니다. 자주 만질 것만 적습니다.

| 값 | 기본 | 뜻 |
|---|---|---|
| `REQUEST_INTERVAL_MS` | 3600 | 요청 사이 간격. 1단계는 1000 으로 줄여도 대개 괜찮습니다 |
| `MAX_SYMBOLS_FOR_BARS` | 150 | 2단계에서 받을 종목 수. 0 이면 제한 없음 |
| `MIN_TURNOVER_WON` | 50억 | 20일 평균 거래대금 최댓값 하한 |
| `MAX_TICK_COST` | 0.0015 | 한 호가가 가격의 0.15% 이하 |
| `DAILY_YEARS` | 2 | 일봉 몇 년치 |
