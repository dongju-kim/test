# 키움 스캘핑 전략 최적화 시스템

키움증권 OpenAPI를 활용한 자동매매 스캘핑 전략 시스템입니다.
다양한 시간프레임(1분, 3분, 5분, 10분봉)과 기술적 지표를 조합하여 최적의 수익률을 추구합니다.

## 📊 핵심 분석 결과

### 🏆 최적 전략
**전략 B: 볼린저밴드 반등 전략 (3분봉)**

#### 선택 이유
1. ✅ **3분봉의 우수성**
   - 1분봉의 노이즈 필터링
   - 충분한 거래 기회 (하루 약 120회)
   - 기술적 지표의 높은 신뢰도
   - 스캘핑과 단타의 최적 균형점

2. ✅ **볼린저밴드 전략의 강점**
   - 한국 시장의 평균회귀 성향에 적합
   - 명확한 진입/청산 신호
   - RSI + MACD + 거래량 다중 확인
   - 높은 승률 (목표 70%)

3. ✅ **리스크/수익 비율**
   - 손절: -0.7%
   - 익절: +2.0%
   - 리스크 대비 약 2.86배 수익

## 🚀 빠른 시작

### 1. 설치
```bash
pip install -r requirements.txt
```

### 2. 백테스팅 실행
```bash
python backtest_example.py
```

### 3. 실전 자동매매 (키움 API 연동 필요)
```python
from kiwoom_api_connector import KiwoomAPI, AutoTradingSystem
from kiwoom_scalping_strategies import StrategyManager

# 키움 API 초기화
kiwoom = KiwoomAPI()
kiwoom.comm_connect()

# 전략 매니저 초기화
strategy_manager = StrategyManager()

# 자동매매 시스템 설정
auto_trading = AutoTradingSystem(kiwoom, strategy_manager)
auto_trading.add_target_stock('005930', '삼성전자', 'strategy_b', '3')

# 실행
auto_trading.run()
```

## 💡 주요 기능

### 1. 다양한 스캘핑 전략

#### Strategy A: RSI 평균회귀 (3분봉)
```python
진입 조건:
- RSI(14) < 30 (과매도)
- 거래량 > 평균의 1.5배
- 5EMA > 20EMA (상승 추세)

청산 조건:
- RSI(14) > 50 (중립)
- 또는 +1.5% 익절 / -0.5% 손절
```

#### Strategy B: 볼린저밴드 반등 (3분봉) ⭐ 추천
```python
진입 조건:
- 가격이 하단 볼린저밴드 터치
- RSI(9) < 35
- MACD 히스토그램 상승 전환
- 거래량 > 평균의 2배

청산 조건:
- 가격이 중심선(20MA) 도달
- 또는 +2% 익절 / -0.7% 손절
```

#### Strategy C: 모멘텀 브레이크아웃 (1분봉)
```python
진입 조건:
- 5분간 최고가 돌파
- 60 < RSI(7) < 80
- 거래량 > 평균의 3배
- ATR 확대

청산 조건:
- RSI(7) < 50
- 또는 +1% 익절 / -0.3% 손절
```

#### Strategy D: VWAP 회귀 (5분봉)
```python
진입 조건:
- 가격이 VWAP에서 -1.5% 이상 괴리
- RSI(14) < 40
- 거래량 증가 추세

청산 조건:
- 가격이 VWAP 복귀
- 또는 +1% 익절 / -0.5% 손절
```

### 2. 백테스팅 프레임워크
```python
from kiwoom_scalping_strategies import StrategyManager

manager = StrategyManager()

# 전략 실행
signal = manager.execute_strategy('strategy_b', df)

# 백테스팅
results = manager.backtest('strategy_b', df, initial_capital=10000000)
print(f"승률: {results['win_rate']:.2f}%")
print(f"수익률: {results['total_return_pct']:.2f}%")
```

### 3. 리스크 관리 시스템
- 1회 거래당 총 자금의 1% 이내 리스크
- 일일 손실 한도: 총 자금의 2%
- 손절비 1 : 익절비 2 이상 유지
- 동시 보유 종목 최대 3개

## 📈 시간프레임별 특성

### 1분봉
- **장점**: 거래 기회 최다 (360회/일), 빠른 대응
- **단점**: 노이즈 많음, 수수료 부담, 정신적 스트레스

- **단점**: 스캘핑보다는 단타
- **추천**: 안정적 수익 추구

### 10분봉
- **장점**: 매우 안정적
- **단점**: 기회 매우 적음 (36회/일), 스캘핑 부적합

## ⚠️ 주의사항

### 백테스팅 vs 실전
1. **슬리피지**: 백테스팅은 체결가격 차이 미반영
2. **수수료**: 실전에서 0.015% 왕복 약 0.03% 발생
3. **미체결**: 급변동 시 주문 미체결 가능성
4. **심리**: 실전에서 감정 개입 주의

### 리스크 관리
1. ✅ **절대 규칙**: 손절가 이탈 금지
2. ✅ **일일 한도**: 2% 손실 시 당일 거래 중단
3. ✅ **연속 손실**: 3회 연속 손실 시 전략 재검토
4. ✅ **소액 시작**: 충분한 검증 후 자금 확대

### 최적 거래 시간대
- 09:00~09:30: ⚠️  변동성 큼 (초보자 비추천)
- 09:30~11:00: ✅ **최적** (거래량↑, 추세 명확)
- 11:00~13:00: ❌ 관망 (점심시간 거래량↓)
- 13:00~14:30: ✅ 2차 활성 시간
- 14:30~15:20: ⚠️  장 마감 변동성↑
